## 기존 과제 기준 유지

- 제공 초기 데이터로 먼저 구현·검증한 뒤 별도 테스트 환경에서 대량 데이터를 생성·검증한다.
- 실행 명령, 초기·테스트 환경 선택 및 재생성·검증 방법은 실제 구현 후 SUBMISSION.md에 기록한다.
- API 문서는 실제 구현과 일치하게 docs/에 작성한다.
- PDF는 선택 가능한 텍스트를 포함한다. 제출물에 앱·데이터 생성 코드·전체 SPEC·API 문서·PDF·SUBMISSION.md를 포함한다.
- 기존 자료는 보존하고 비밀번호·API 키·개인정보·불필요한 설치 폴더는 제출에서 제외한다.
