# SPEC 003: 추가 요구사항 4개

## 승인과 상태

2026-09-29: AI가 제안한 일괄 승인안 15~18번과 그 이유를 사용자가 전체 승인했다. 아래 ADD 번호는 기존 요구사항 1~29와 별개다. 모두 구현·검증 전이다.

| ID | 승인안 | 추가 요구사항 | 필요한 이유 |
|---|---|---|---|
| ADD-01 | 15 | 고객별 기본 배송지를 지정하고 주문 시 자동 선택한다. | 반복 주문의 입력을 줄인다. |
| ADD-02 | 16 | 고객별 최근 본 상품 옵션 10개를 저장·조회하고 전체 삭제할 수 있다. | 살펴본 상품을 다시 찾기 쉽게 한다. |
| ADD-03 | 17 | 장바구니 상품을 나중에 구매 목록으로 이동하고 복원할 수 있다. | 주문을 미룰 상품을 장바구니와 분리한다. |
| ADD-04 | 18 | 현재 검색·필터 결과에 해당하는 주문 내역을 CSV로 다운로드한다. 금액·취소 상태를 포함하고 배송 개인정보는 제외한다. | 구매 기록을 따로 보관할 수 있다. |

## 구현·확인 기록

- 앱 구현: 미착수.
- AI 동작 검사: 미실행.
- 사람의 화면 조작 확인: 미실행.
- 사용자가 승인하지 않은 세부 정책을 확정한 것으로 기록하지 않는다. 추가 판단이 필요하면 구현 전에 제안한다.

## 후속 구현·확인 기록 (2026-09-29, 사후 정리)

위 ‘미착수·미실행’은 승인 당시 상태다. 이후 ADD-01 기본 배송지 지정·자동 선택, ADD-02 최근 본 옵션 10개·전체 삭제, ADD-03 나중에 구매 목록 이동·복원, ADD-04 현재 주문 검색·상태 필터에 맞춘 CSV 다운로드를 구현했다. 서버의 고객별 자료와 CSV 생성은 `server/core.ts`, 화면 동작은 `src/main.tsx`에 있다. 첫 배송지 등록 후 자동 선택 오류와 후속 브라우저 확인은 [SPEC 006](006-address-default-fix.md)에, 주문 CSV의 검색·필터 대조는 [주문 흐름 검토](007-order-review.md)에 기록됐다. `tests/shop.test.ts`에는 최근 본 목록 제한, 저장 목록 분리, CSV에서 배송 개인정보 제외 등의 사례가 있다. 이번 문서 보완에서 검사를 새로 실행하지 않았으며, 사람의 직접 화면 확인 결과는 아직 받지 않았다.
