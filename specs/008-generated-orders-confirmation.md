# SPEC 008: 생성 주문의 확인 키 전달

- 문제: 주문 확정에 `confirmationKey` 검증이 추가된 뒤 `scripts/generate.ts`는 키 없이 `order.place`를 호출했다. 따라서 별도 대량 데이터 생성이 첫 주문에서 실패했다.
- 처리: 생성기 역시 상품을 장바구니에 담은 다음 `quote()`로 현재 주문 내용을 확인하고, 반환된 `confirmationKey`를 바로 이어지는 `order.place`에 전달한다. 주문·취소 사례의 구성과 초기 데이터 분리 방식은 유지한다.
- 검증 결과: 수정 후 별도 SQLite 파일에 상품 옵션 200개, 고객 100명, 주문 800건을 생성했다. 생성기 자체 검사에서 재고·취소 금액 정합성이 통과했고, 저장된 DB를 다시 읽어 세 종류의 건수를 확인했다. 같은 파일로 재실행하면 기존 자료를 보존하며 오류로 종료한다. `npm test` 12건 통과.
- 사용자 화면 확인과 제출 문서 갱신은 별도 작업이다.
