# SPEC 009: 같은 옵션을 다시 담을 때 확인

## 결정과 범위

- 2026-09-29 사용자 요청: 찜한 옵션이 이미 장바구니에 있을 때 다시 담기를 누르면 확인 메시지와 선택 버튼을 제공한다.
- AI 제안: 현재 수량, 추가 수량, 합산 수량을 보여 주고 `추가로 담기`와 `취소`를 제공한다. 취소하면 장바구니를 바꾸지 않는다.
- 사용자 결정: 확인창을 찜 목록과 상품 목록 양쪽에 적용한다. 선택 이유는 별도로 말하지 않았다.
- 사용자는 먼저 기록을 미루자고 했고, 구현을 마친 뒤 기록해 달라고 후속 요청했다.
- 범위: 두 목록의 `담기` 버튼. 최근 본 상품 화면의 담기 버튼은 이번 결정에 포함되지 않았다.

## 구현

- 같은 SKU가 현재 고객의 장바구니에 있을 때만 확인창을 띄운다. 장바구니에 없는 옵션은 바로 담는다.
- 확인창은 옵션명, 기존 수량, 추가 수량, 합산 수량을 보여 준다. `취소`와 Escape는 추가 요청을 보내지 않는다.
- `추가로 담기`를 누르면 기존 `cart.add` API를 호출해 한 줄로 합친다. 연속 요청을 막고, 서버의 1~99개·재고 검사도 유지한다. 찜 상태는 바꾸지 않는다.
- 이번 변경은 화면 동작만 수정했다. API 형식은 바뀌지 않았다.

## AI가 실행한 확인

별도 시험 DB `/tmp/shop-duplicate-confirmation-review.sqlite`에서 초기 데이터를 사용했다.

| 사례 | 실행 전 기대 | 실제 결과 |
|---|---|---|
| 상품 목록에서 SKU 1을 처음 1개 담기 | 확인창 없이 장바구니 한 줄 1개 | 확인창 없이 담겼고 장바구니 줄 수 1개 |
| 상품 목록에서 같은 SKU 1을 다시 1개 담고 취소 | 기존 1개 유지 | 확인창에 `1개 + 1개 = 2개`가 보였고 취소 뒤 1개 유지 |
| 찜 목록에서 같은 SKU 1을 다시 1개 담고 추가 선택 | 한 줄 2개, 38,000원, 찜 유지, 재고 3개 유지 | 장바구니 한 줄 2개·38,000원, 찜 목록에 SKU 1 유지, 저장 DB 재고 3개 |
| 기존 2개에 2개 추가 시도 | 현재 재고 3개 초과 안내, 수량 불변 | `현재 재고는 3개입니다.` 표시, 확인창 없이 거절 |

## 사람이 확인할 사례

상품 목록에서 옵션을 1개 담고 같은 옵션의 `담기`를 다시 누른다. 확인창의 수량을 읽고 `취소`를 눌러 수량이 그대로인지 본다. 찜 목록에서 같은 옵션의 `담기`를 눌러 `추가로 담기`를 선택한 뒤 장바구니 줄 수량과 금액을 대조한다.
